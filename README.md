# Hotel Booking Stream Processing

Лабораторна робота №3 з дисципліни «Професійний Python»

## Опис проєкту

Модуль для потокової обробки та аналізу великих наборів даних бронювань готелю без повної матеріалізації колекцій у пам'яті (Варіант 8).  
Проєкт демонструє роботу з ітераційною моделлю Python, ітераторами (`__iter__`, `__next__`), генераторними функціями (`yield`), делегуванням генерації (`yield from`), генераторними виразами, модульними засобами `itertools` (`islice`, `accumulate`, `pairwise`, `chain`), організацією потокових конвеєрів (streaming lazy pipeline), пакетною обробкою (`batching`) та порівнянням ефективності `eager` проти `lazy evaluation` за допомогою `tracemalloc`.

## Структура проєкту (src-layout)

```text
hotel_stream/
│
├── pyproject.toml
├── README.md
├── .gitignore
├── generate_data.py
├── benchmarks.py
├── data/
│   └── bookings.csv
└── src/
    └── stream_processor/
        ├── __init__.py
        ├── models.py
        ├── readers.py
        ├── parsers.py
        ├── filters.py
        ├── transformations.py
        ├── batches.py
        ├── analytics.py
        ├── iterators.py
        ├── pipeline.py
        └── main.py
```

- `generate_data.py` — генератор тестових наборів даних бронювань (до 500 000+ записів із додаванням пошкоджених рядків для перевірки валідації).
- `benchmarks.py` — експериментальний модуль замірів часу виконання (`elapsed time`), пікової пам'яті (`peak memory` через `tracemalloc`) та ефекту дострокового переривання (`early termination`) для eager і lazy підходів.
- `models.py` — типізована модель кімнати `RoomRecord` на базі `NamedTuple`.
- `readers.py` — функція `read_lines()` для потокового читання файлу через `yield from`.
- `parsers.py` — порядковий парсинг CSV-рядків за допомогою `csv.DictReader` і `yield from`.
- `filters.py` — генератори валідації даних (`validate_rooms`) та ледачої фільтрації за статусом (`available`/`booked`), типом і ціною.
- `transformations.py` — потокова нормалізація текстових полів (`normalize_records`).
- `batches.py` — потокове розбиття даних на батчі фіксованого розміру через `itertools.islice`.
- `analytics.py` — однопрохідний розрахунок загальної та заброньованої виручки, підрахунок бронювань і пошук найдешевшого вільного номера з пам'яттю O(1).
- `iterators.py` — власний Iterator-клас `RoomPriceRangeIterator`, Iterable-контейнер `HotelRoomCatalog` та розширені операції `itertools` (`accumulate`, `pairwise`, `chain`).
- `pipeline.py` — збирання багатостадійного потокового конвеєра (streaming lazy pipeline).
- `main.py` — точка входу: демонстрація виконання всіх пунктів завдання варіанта 8.

## Вимоги

- Python 3.11+
- uv (або стандартний venv)

## Встановлення та запуск

1. Створення віртуального оточення та синхронізація через `uv`:

```bash
uv venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

2. Генерація тестового датасету:

```bash
uv run generate_data.py
```

3. Запуск основного демонстраційного конвеєра:

```bash
uv run python -m src.stream_processor.main
```

4. Запуск експериментального порівняння (Eager vs Lazy):

```bash
uv run benchmarks.py
```
